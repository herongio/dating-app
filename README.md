# dating-app

A dating app built with React Native (Expo).

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (18+)
- The [Expo Go](https://expo.dev/go) app on your phone (iOS or Android)

### Run it

```bash
npm install
npx expo start
```

A QR code will appear in the terminal. Scan it with the Expo Go app (Android: in-app scanner; iOS: Camera app) to run the app on your phone.

## Project Structure

```
dating-app/
├── App.js          # Main screen — profile cards with Like/Pass
├── profiles.js      # Mock profile data
├── app.json         # Expo app config
└── package.json
```
